# ☀️ Morning Peace

> Start your mornings without distractions

Morning Peace is an Android app designed to help you reclaim your mornings and focus sessions by blocking distracting phone usage.

## ✨ Features

- **☀️ Morning Block** — Auto-detects sleep patterns and blocks apps when you wake up.
- **🎯 Focus Lock** — Instant focus sessions (15min, 30min, 1hr, 2hr).
- **📱 App Whitelist** — Choose which apps stay accessible during blocks.
- **🔒 Lock Screen** — Beautiful overlay that encourages mindful mornings.
- **🔄 Auto-Update** — App checks for updates from GitHub Releases automatically.

## 🚀 How It Works

1. **Set Up**: Configure your wake-up time or let the app detect your sleep patterns.
2. **Whitelist**: Select essential apps (like Alarm, Phone) that shouldn't be blocked.
3. **Rest Easy**: When you wake up, distractions are locked behind a mindful overlay.
4. **Focus**: Use quick focus sessions throughout the day when you need deep work.

## 🔐 Permissions

To function effectively, Morning Peace requires the following permissions:
- **Accessibility Service**: To detect when you launch a distracting app and show the block overlay.
- **Display Over Other Apps (Overlay)**: To show the beautiful mindful lock screen over blocked apps.
- **Exact Alarm**: To accurately trigger morning blocks and focus sessions.
- **Usage Access**: To monitor app usage and detect sleep patterns.

## 🛠️ Tech Stack

- **Language**: Kotlin
- **SDK**: Android SDK 34
- **UI**: View Binding, Material Design
- **Architecture**: Modern Android Architecture
